# Slice 11 — Sparkle + Release Pipeline Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship in-app "Check for Updates" backed by Sparkle 2 + EdDSA-signed appcast on GitHub Releases. A v0.9 build can find, verify, and install a v1.0 build end-to-end.

**Architecture:** Add the Sparkle SPM package as a direct dependency. Configure `SUFeedURL` and `SUPublicEDKey` in `Info.plist`. Wire `SPUStandardUpdaterController` into `AppDelegate` and expose "Check for Updates…" in the menu-bar menu. Build pipeline becomes three scripts: `setup-sparkle-key.sh` (one-shot keygen → Keychain), `build-release.sh` (archive → export → zip → EdDSA-sign), `publish-release.sh` (generate appcast item → `gh release create`). `appcast.xml` is generated by a tiny pure-Swift helper that we unit-test; the script invokes it.

**Tech Stack:** Sparkle 2 (SwiftPM), `xcodebuild -archivePath` + `-exportArchive`, `sign_update` (bundled in Sparkle artifact), `security` (macOS Keychain CLI), `gh` (GitHub CLI), XCTest.

**Locked decisions (from PRD):**
- Sparkle EdDSA private key lives in login Keychain as a generic password named `SayMoore Sparkle EdDSA`, account `default`. Never on disk plaintext.
- Code signing identity is `SayMoore Self-Sign` (already set up in Slice 0).
- Appcast hosted at `https://github.com/seemoretmoore/saymoore/releases/latest/download/appcast.xml` (asset on the rolling "latest" release).
- v0.9 / v1.0 are the test versions for the end-to-end update demo. App ships at `MARKETING_VERSION 0.9.0` after this slice; Slice 12 bumps to `1.0.0`.

## Task 2: Sparkle key setup script

**Files:**
- Create: `scripts/setup-sparkle-key.sh`

- [ ] **Step 1: Write the script**

```bash
#!/usr/bin/env bash
# Generate an EdDSA key pair for Sparkle appcast signing, store the private key
# in the login Keychain, and print the public key so it can be pasted into
# Info.plist as SUPublicEDKey.
#
# Idempotent: refuses to overwrite an existing key unless --force-regen is passed.
# Re-running with --force-regen will break updates for any already-shipped build
# whose Info.plist pins the old public key.

set -euo pipefail

ACCOUNT="default"
SERVICE="SayMoore Sparkle EdDSA"
FORCE=0
for arg in "$@"; do
    case "$arg" in
        --force-regen) FORCE=1 ;;
        *) echo "unknown arg: $arg" >&2; exit 2 ;;
    esac
done

if security find-generic-password -a "$ACCOUNT" -s "$SERVICE" >/dev/null 2>&1; then
    if [[ $FORCE -ne 1 ]]; then
        echo "error: Keychain entry '$SERVICE' already exists. Re-run with --force-regen ONLY if you intend to invalidate every shipped build." >&2
        exit 1
    fi
    security delete-generic-password -a "$ACCOUNT" -s "$SERVICE" >/dev/null
    echo "warning: rotating Sparkle key — all builds signed with the old key will stop receiving updates." >&2
fi

# Locate Sparkle's generate_keys (shipped inside the SPM artifact).
SPARKLE_DERIVED=$(find ~/Library/Developer/Xcode/DerivedData -type f -name generate_keys 2>/dev/null | head -1 || true)
if [[ -z "$SPARKLE_DERIVED" ]]; then
    echo "error: Sparkle's generate_keys not found. Build the SayMoore target once first (it resolves the Sparkle SPM package)." >&2
    exit 1
fi

TMP=$(mktemp -d)
trap 'rm -rf "$TMP"' EXIT

# generate_keys writes the keypair to a local file in the current directory.
( cd "$TMP" && "$SPARKLE_DERIVED" -p ) >"$TMP/output.txt"

# generate_keys prints both keys to stderr; -p emits the public key on stdout
# and stashes the private key in the keychain on its own. Newer Sparkle stores
# the private key under service "https://sparkle-project.org" / account "ed25519"
# — we mirror it under our preferred service name so build-release.sh has a
# stable lookup, and remove the upstream entry to avoid two copies.
PUBLIC_KEY=$(tr -d '[:space:]' <"$TMP/output.txt")

PRIVATE_KEY=$(security find-generic-password -a ed25519 -s "https://sparkle-project.org" -w 2>/dev/null || true)
if [[ -z "$PRIVATE_KEY" ]]; then
    echo "error: generate_keys did not stash a private key in the default keychain entry." >&2
    exit 1
fi
security add-generic-password -a "$ACCOUNT" -s "$SERVICE" -w "$PRIVATE_KEY" -T "" -U
security delete-generic-password -a ed25519 -s "https://sparkle-project.org" >/dev/null 2>&1 || true

echo
echo "==============================================================="
echo "Sparkle EdDSA key generated."
echo
echo "Public key (paste into Info.plist <key>SUPublicEDKey</key>):"
echo
echo "  $PUBLIC_KEY"
echo
echo "Private key stored in login Keychain as:"
echo "  service='$SERVICE' account='$ACCOUNT'"
echo "==============================================================="
```

// SayMoore/Services/UpdaterService.swift
import AppKit
import Sparkle

/// Owns Sparkle's `SPUStandardUpdaterController`. Exposes a single action the
/// menu-bar "Check for Updates…" item can target. Initialised lazily on first
/// access; once created, Sparkle handles scheduled background checks per
/// `SUScheduledCheckInterval` in Info.plist.
@MainActor
final class UpdaterService: NSObject {
    static let shared = UpdaterService()

    private let controller: SPUStandardUpdaterController

    override init() {
        // startingUpdater=true is correct: we want background checks to begin
        // immediately on launch (subject to SUEnableAutomaticChecks).
        self.controller = SPUStandardUpdaterController(
            startingUpdater: true,
            updaterDelegate: nil,
            userDriverDelegate: nil
        )
        super.init()
    }

    @objc func checkForUpdates(_ sender: Any?) {
        controller.checkForUpdates(sender)
    }
}
```

// scripts/lib/appcast.swift
import Foundation

enum AppcastGenerator {
    static func item(
        version: String,
        buildNumber: String,
        minSystemVersion: String,
        zipURL: String,
        edSignature: String,
        length: Int64,
        pubDate: String
    ) -> String {
        """
        <item>
            <title>Version \(version)</title>
            <pubDate>\(pubDate)</pubDate>
            <sparkle:minimumSystemVersion>\(minSystemVersion)</sparkle:minimumSystemVersion>
            <enclosure
                url="\(zipURL)"
                sparkle:version="\(buildNumber)"
                sparkle:shortVersionString="\(version)"
                length="\(length)"
                type="application/octet-stream"
                sparkle:edSignature="\(edSignature)" />
        </item>
        """
    }

    static func feed(items: [String]) -> String {
        """
        <?xml version="1.0" standalone="yes"?>
        <rss version="2.0" xmlns:sparkle="http://www.andymatuschak.org/xml-namespaces/sparkle">
        <channel>
            <title>SayMoore</title>
            <link>https://github.com/seemoretmoore/saymoore</link>
            <description>SayMoore release feed.</description>
            <language>en</language>
        \(items.joined(separator: "\n"))
        </channel>
        </rss>
        """
    }
}

// CLI entry-point — only runs when invoked as `swift scripts/lib/appcast.swift ...`.
// Args: <version> <buildNumber> <minSystemVersion> <zipURL> <edSignature> <length> <pubDate>
// Existing-feed merge happens in publish-release.sh (it reads the current
// appcast, parses out existing <item> blocks, prepends the new one, and
// re-wraps).
#if !TEST
if CommandLine.arguments.count == 8 {
    let a = CommandLine.arguments
    let item = AppcastGenerator.item(
        version: a[1], buildNumber: a[2], minSystemVersion: a[3],
        zipURL: a[4], edSignature: a[5], length: Int64(a[6]) ?? 0, pubDate: a[7]
    )
    print(item)
}
#endif
```

- [ ] **Step 1: Replace with full archive + sign flow**

```bash
#!/usr/bin/env bash
# Build a release-configuration archive of SayMoore, export it, zip the .app,
# and EdDSA-sign the zip using the private key stored in the login Keychain.
#
# Outputs under release/<version>/:
#   SayMoore-<version>.zip          — zipped .app bundle
#   SayMoore-<version>.sig          — base64 EdDSA signature (single line)
#   SayMoore-<version>.length       — byte length of the zip
#
# Exit codes: 0 success, non-zero on any failure (set -e).

set -euo pipefail

cd "$(dirname "$0")/.."

if [[ ! -d SayMoore.xcodeproj ]]; then
    bash scripts/generate-project.sh
fi

# Pull version straight from the generated project (single source of truth).
VERSION=$(awk -F' = ' '/MARKETING_VERSION = /{gsub(";",""); print $2; exit}' SayMoore.xcodeproj/project.pbxproj | tr -d ' ')
BUILD=$(awk -F' = ' '/CURRENT_PROJECT_VERSION = /{gsub(";",""); print $2; exit}' SayMoore.xcodeproj/project.pbxproj | tr -d ' ')
if [[ -z "$VERSION" || -z "$BUILD" ]]; then
    echo "error: could not parse MARKETING_VERSION / CURRENT_PROJECT_VERSION from project.pbxproj" >&2
    exit 1
fi

OUT="release/$VERSION"
mkdir -p "$OUT"
ARCHIVE="build/SayMoore-$VERSION.xcarchive"
EXPORT_DIR="build/export-$VERSION"
rm -rf "$ARCHIVE" "$EXPORT_DIR"

xcodebuild \
    -project SayMoore.xcodeproj \
    -scheme SayMoore \
    -configuration Release \
    -derivedDataPath build/ \
    -archivePath "$ARCHIVE" \
    CODE_SIGN_IDENTITY="SayMoore Self-Sign" \
    CODE_SIGN_STYLE=Manual \
    archive

cat > "build/exportOptions.plist" <<'PLIST'
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>method</key><string>mac-application</string>
    <key>signingStyle</key><string>manual</string>
    <key>signingCertificate</key><string>SayMoore Self-Sign</string>
</dict>
</plist>
PLIST

xcodebuild -exportArchive \
    -archivePath "$ARCHIVE" \
    -exportPath "$EXPORT_DIR" \
    -exportOptionsPlist "build/exportOptions.plist"

APP="$EXPORT_DIR/SayMoore.app"
[[ -d "$APP" ]] || { echo "error: $APP missing after export" >&2; exit 1; }

# Reject adhoc signing — same guard as the in-target post-build phase.
if codesign -dvv "$APP" 2>&1 | grep -qE 'flags=0x2\(adhoc\)|Signature=adhoc'; then
    echo "error: exported app is ad-hoc signed; run scripts/setup-signing.sh" >&2
    exit 1
fi

ZIP="$OUT/SayMoore-$VERSION.zip"
( cd "$EXPORT_DIR" && /usr/bin/ditto -c -k --keepParent SayMoore.app "../../$ZIP" )

# Locate Sparkle's sign_update (shipped with the SPM artifact).
SIGN_UPDATE=$(find ~/Library/Developer/Xcode/DerivedData -type f -name sign_update 2>/dev/null | head -1 || true)
[[ -n "$SIGN_UPDATE" ]] || { echo "error: sign_update not found; build SayMoore once to resolve Sparkle" >&2; exit 1; }

# Fetch private key from Keychain → pipe into sign_update.
PRIV=$(security find-generic-password -a default -s "SayMoore Sparkle EdDSA" -w 2>/dev/null || true)
[[ -n "$PRIV" ]] || { echo "error: Keychain entry 'SayMoore Sparkle EdDSA' not found; run scripts/setup-sparkle-key.sh" >&2; exit 1; }

# sign_update accepts a key file path with -f, so we pipe via a temp file in an
# in-memory dir (/tmp on Darwin is on APFS but never inspected by Sparkle here).
KEYFILE=$(mktemp)
trap 'rm -f "$KEYFILE"' EXIT
printf '%s' "$PRIV" > "$KEYFILE"
chmod 600 "$KEYFILE"

SIG_LINE=$("$SIGN_UPDATE" -f "$KEYFILE" "$ZIP")
# sign_update prints e.g.: sparkle:edSignature="..." length="..."
echo "$SIG_LINE" | sed -E 's/.*sparkle:edSignature="([^"]+)".*/\1/' > "$OUT/SayMoore-$VERSION.sig"
stat -f%z "$ZIP" > "$OUT/SayMoore-$VERSION.length"

echo
echo "✓ Built and signed:"
echo "    $ZIP"
echo "    signature: $(cat "$OUT/SayMoore-$VERSION.sig")"
echo "    length:    $(cat "$OUT/SayMoore-$VERSION.length") bytes"
echo "    version:   $VERSION (build $BUILD)"
```

```bash
#!/usr/bin/env bash
# Publish the current release: upload the zip to a new GitHub Release, generate
# a fresh appcast.xml (newest item first, keeping the previous one as history),
# and attach the appcast as a release asset on the "latest" rolling tag.
#
# Requires: gh authenticated against github.com/seemoretmoore/saymoore.

set -euo pipefail

cd "$(dirname "$0")/.."

# Ensure the build artifacts exist; build if not.
bash scripts/build-release.sh

VERSION=$(awk -F' = ' '/MARKETING_VERSION = /{gsub(";",""); print $2; exit}' SayMoore.xcodeproj/project.pbxproj | tr -d ' ')
BUILD=$(awk -F' = ' '/CURRENT_PROJECT_VERSION = /{gsub(";",""); print $2; exit}' SayMoore.xcodeproj/project.pbxproj | tr -d ' ')
OUT="release/$VERSION"
ZIP="$OUT/SayMoore-$VERSION.zip"
SIG=$(cat "$OUT/SayMoore-$VERSION.sig")
LEN=$(cat "$OUT/SayMoore-$VERSION.length")
TAG="v$VERSION"
ZIP_URL="https://github.com/seemoretmoore/saymoore/releases/download/$TAG/SayMoore-$VERSION.zip"
PUBDATE=$(LC_ALL=C date -u "+%a, %d %b %Y %H:%M:%S +0000")

# Build the new item via the generator.
NEW_ITEM=$(swift scripts/lib/appcast.swift \
    "$VERSION" "$BUILD" "14.0" "$ZIP_URL" "$SIG" "$LEN" "$PUBDATE")

# Pull the existing appcast (if any) and extract previous <item> blocks.
EXISTING_ITEMS=""
if gh release view latest --repo seemoretmoore/saymoore >/dev/null 2>&1; then
    if gh release download latest --repo seemoretmoore/saymoore -p appcast.xml -O /tmp/appcast.xml.old 2>/dev/null; then
        # Crude but reliable item extraction. Awk between <item> and </item>.
        EXISTING_ITEMS=$(awk '/<item>/,/<\/item>/' /tmp/appcast.xml.old || true)
    fi
fi

ALL_ITEMS="$NEW_ITEM"
if [[ -n "$EXISTING_ITEMS" ]]; then
    ALL_ITEMS="$NEW_ITEM
$EXISTING_ITEMS"
fi

# Wrap in the channel feed by invoking the generator's CLI in a different mode:
# easier to just inline the wrapper since the feed wrapper is trivial.
cat > "$OUT/appcast.xml" <<EOF
<?xml version="1.0" standalone="yes"?>
<rss version="2.0" xmlns:sparkle="http://www.andymatuschak.org/xml-namespaces/sparkle">
<channel>
    <title>SayMoore</title>
    <link>https://github.com/seemoretmoore/saymoore</link>
    <description>SayMoore release feed.</description>
    <language>en</language>
$ALL_ITEMS
</channel>
</rss>
EOF

# Versioned release: create + upload zip.
if gh release view "$TAG" --repo seemoretmoore/saymoore >/dev/null 2>&1; then
    echo "release $TAG already exists; uploading assets with --clobber"
    gh release upload "$TAG" "$ZIP" --clobber --repo seemoretmoore/saymoore
else
    gh release create "$TAG" "$ZIP" \
        --repo seemoretmoore/saymoore \
        --title "SayMoore $VERSION" \
        --notes "Automated release. See CHANGELOG for details."
fi

# Rolling "latest" release: holds the current appcast.xml.
if ! gh release view latest --repo seemoretmoore/saymoore >/dev/null 2>&1; then
    gh release create latest \
        --repo seemoretmoore/saymoore \
        --title "Latest appcast" \
        --notes "Rolling release that hosts the current appcast.xml. Do not delete."
fi
gh release upload latest "$OUT/appcast.xml" --clobber --repo seemoretmoore/saymoore

echo
echo "✓ Published $VERSION"
echo "    zip: $ZIP_URL"
echo "    appcast: https://github.com/seemoretmoore/saymoore/releases/latest/download/appcast.xml"
```
